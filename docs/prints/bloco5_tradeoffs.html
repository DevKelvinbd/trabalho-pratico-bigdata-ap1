Motor de Streaming ✔ Apache Flink ✖ Apache Spark Streaming Flink é nativamente orientado a eventos (latência sub-segundo registro a registro) e gerencia Event Time com Watermarks para eventos com atraso, enquanto o Spark opera por micro-batches.
Armazenamento de Alertas ✔ Apache HBase ✖ Persistência Direta HDFS O HDFS é voltado para throughput de leitura sequencial (write-once, read-many). O HBase provê leitura e escrita pontual randômica por chave (RowKey reversa) em < 5ms para operação.
Data Warehouse Analítico ✔ Apache Hive DW ✖ Consultas JSON em HDFS O Hive provê catálogo semântico (Metastore), formato colunar ORC com compressão e Partition Pruning por data (dt), economizando até 85% de I/O de rede e disco.
Ingestão Resiliente ✔ Apache Flume (TAILDIR) ✖ Scripts Shell / Cron Flume mantém ponteiro transacional em arquivo de posição (sem perda ou duplicidade após falhas) e realiza Fan-out simultâneo para HDFS e Flink sem onerar a aplicação geradora.

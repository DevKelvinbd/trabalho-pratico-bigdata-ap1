docs/justificativas_tecnicas.md Síntese das 4 Decisões de Projeto
1. Apache Flink vs Apache Spark Streaming ✔ Flink Adotado
Flink é nativamente orientado a eventos (latência registro a registro < 50ms) e gerencia Event Time com Watermarks para dados fora de ordem. Spark Streaming opera em micro-batches com latência superior a 500ms.
2. Apache HBase vs Persistência Direta no HDFS ✔ HBase Adotado
HDFS é write-once, read-many voltado para throughput sequencial de arquivos grandes. O HBase provê leitura e escrita pontual randômica por chave (RowKey reversa) em < 5ms para alertas operacionais de suporte e logística.
3. Apache Hive DW vs Consultas Diretas em JSON no HDFS ✔ Hive Adotado
O Hive provê Metastore de metadados, formato colunar comprimido ORC e Partition Pruning por data (dt), cortando mais de 80% do I/O de rede e disco em dashboards de BI comparado a varrer JSON bruto.
4. Apache Flume (TAILDIR) vs Scripts Shell / Cron ✔ Flume Adotado
Flume mantém ponteiro transacional em arquivo de posição persistente (sem perda de dados pós-crash) e realiza Fan-out simultâneo (HDFS + Flink) sem onerar a aplicação geradora.
